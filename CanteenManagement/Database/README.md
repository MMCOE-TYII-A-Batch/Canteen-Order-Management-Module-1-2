# Canteen Order Management System

## About the Project

The **Canteen Order Management System** is a web-based application developed using **Java, JSP, Servlets, JDBC, and MySQL**. It manages users, roles, food categories, dishes, and customer orders efficiently.

## Database

**Database Name:** `canteen_management`

### Tables

- `roles`
- `users`
- `categories`
- `dishes`
- `orders`
- `order_items`
