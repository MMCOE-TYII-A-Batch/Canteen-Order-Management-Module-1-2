# Canteen Order Management System

## About the Project

The **Canteen Order Management System** is a web-based application developed using **Java, JSP, Servlets, JDBC, and MySQL**.

The database manages users, roles, food categories, dishes, and customer orders in a structured way.

---

## Database

**Database Name:** `canteen_management`

### Current Tables

- `roles`
- `users`
- `categories`
- `dishes`
- `orders`
- `order_items`

---

## Database Setup

Create the database using:

```sql
CREATE DATABASE IF NOT EXISTS canteen_management;
USE canteen_management;
